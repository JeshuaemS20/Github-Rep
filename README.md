# StudyCalc AI

The Expo / React Native app is in **`my-app/`** (Expo Router template).

## Run the app

From this folder:

```bash
cd my-app
npm install
npm start
```

Or from the repo root (after `npm install` inside `my-app` once):

```bash
npm run start
```

Then press `a` / `i` / `w` for Android, iOS simulator, or web.

## Avoid `npx expo` lock errors (Windows)

Use the local CLI:

```bash
cd my-app
npm exec expo start
```

or `npm start` from `my-app` (uses `expo` from `node_modules`).
